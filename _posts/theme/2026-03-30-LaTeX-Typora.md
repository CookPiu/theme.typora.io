# LaTeX Typora

LaTeX Typora is a light and dark Typora theme pair inspired by classic LaTeX documents.

![LaTeX Typora light mode](/media/theme/latex-typora/light.png)

<p align="center">Light mode</p>

![LaTeX Typora dark mode](/media/theme/latex-typora/dark.png)

<p align="center">Dark mode</p>

## Features

- Includes `latex.css` and `latex-dark.css` for a matched light/dark pair.
- Bundles Computer Modern web fonts for offline use.
- Uses LaTeX-style spacing, centered titles, and justified paragraphs.
- Styles tables, blockquotes, links, footnotes, math, and Typora UI surfaces in a consistent monochrome look.
- Keeps print and export output aligned with the editor presentation.

## Installation

1. Download the latest release and extract it.
2. In Typora, open `Preferences` -> `Appearance` and click `Open Theme Folder`.
3. Copy `latex.css`, `latex-dark.css`, and the `latex_fonts` folder into Typora's theme folder.
4. Restart Typora and select `latex` or `latex-dark` from the Themes menu.

> Designed and tested on macOS. Not fully tested, but should work for Windows/Linux.

For source, updates, and installation notes, visit [shamsghi/LatexTypora](https://github.com/shamsghi/LatexTypora).
